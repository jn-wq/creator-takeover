# Cases & Assets

Tilfoj nye cases ved at oprette en undermappe her.

## Struktur
```
assets/cases/
  estee-lauder/    <- aktiv case
    videos.md      <- YouTube-links til de 4 videoer
  matas/           <- naeste case (naar klar)
    videos.md
```

## Saadan tilfojer du YouTube-videoer til Slide 6

1. Find YouTube-linket (fx https://youtu.be/ABC123)
2. Aaben Creator Takeover 2026.html i GitHub
3. Find CASE_VIDEOS oeverst i script-blokken og indsaet links
4. Gem - siden viser automatisk YouTube-embeddet i videospot
